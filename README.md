# 🦜 Écho

Le perroquet chante une mélodie, tu la rechantes. Chaque tour, il ajoute une note.
Une fausse note tenue… et il s'envole, vexé.

- Grave ou aigu, peu importe : l'octave ne compte pas.
- Mode Duel à deux sur le même téléphone, avec la même suite de mélodies.
- L'APK est compilé par GitHub Actions et publié sur la branche `apk` (fichier `Echo.apk`).
